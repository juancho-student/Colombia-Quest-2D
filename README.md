# ColombiaQuest

## 📖 Description
ColombiaQuest is a 2D platformer game developed in Unity and inspired by Colombia. This first version (v01) includes a main menu and the first level of the game.

## 🎮 Features
- Main menu.
- Playable Level 1.
- Character movement and jumping.
- Collision detection and object interaction.
- Scene transitions.
- Windows build.

## 💻 Requirements
- A Windows operating system compatible with the build.
- All build files must be kept together in the same folder.

## 🚀 How to Run the Game
1. Download or clone this repository.
2. If you downloaded a ZIP file, extract it to a folder.
3. Open the Windows build folder.
4. Run the game's .exe file.
5. From the main menu, start the game to access Level 1.

**Note:** Do not move the .exe file out of the build folder, as it may require the additional files included with it.

## 🕹️ Controls
- Horizontal movement: Arrow keys.
- Jump: Spacebar.

## 🗺️ Version v01 Content
- Main menu.
- Level 1.
- Basic movement and jumping mechanics.
- Windows build.

## 🛠️ Technologies
- Unity.
- C#.
- 2D Pixel Art.

## 📌 Project Status
First version completed: v01.

This version provides the foundation for future improvements, additional levels, and new features.
