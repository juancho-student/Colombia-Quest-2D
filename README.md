# ColombiaQuest

## Description

ColombiaQuest is a 2D platformer game developed in Unity and inspired by Colombia's history, culture, and heritage.

Version 1.1 expands the gameplay experience with historical challenges, new interactive elements, sound effects, and pixel-art representations of important Colombian landmarks and historical figures.

## Features

- Main menu and scene navigation.
- Playable levels.
- Character movement and jumping.
- Collision detection and object interaction.
- Collectible coins.
- Obstacles and environmental hazards.
- Player life system.
- Historical true/false quiz system.
- Conqueror enemies with independent health systems and quiz challenges.
- Enemy patrol mechanics.
- Door unlocking system based on enemy defeat.
- Victory screen with options to restart, return to the main menu, or continue.
- Sound effects for gameplay events and interactions.
- Historical pixel-art assets inspired by Cartagena.
- Windows build.

## Historical Content

Level 1 takes place in Cartagena and incorporates elements of Colombian history and cultural heritage, including:

- La India Catalina.
- Castillo de San Felipe de Barajas.
- Historical true/false questions.
- Interactive challenges related to Colombian history.

## Requirements

- A Windows operating system compatible with the build.
- All build files must be kept together in the same folder.

## How to Run the Game

1. Download or clone this repository.
2. If you downloaded a ZIP file, extract it to a folder.
3. Open the Windows build folder.
4. Run the game's .exe file.
5. From the main menu, start the game to access the available levels.

**Note:** Do not move the .exe file out of the build folder, as it requires the additional files included with it.

## Controls

- Horizontal movement: Arrow keys.
- Jump: Spacebar.

# ColombiaQuest - Instrucciones en Español

## Descripción

ColombiaQuest es un videojuego 2D de plataformas desarrollado en Unity e inspirado en la historia, la cultura y el patrimonio de Colombia.

La versión 1.1 amplía la experiencia de juego mediante desafíos históricos, nuevos elementos interactivos, efectos de sonido y representaciones en pixel art de lugares y personajes importantes de la historia colombiana.

## Características

- Menú principal y navegación entre escenas.
- Niveles jugables.
- Movimiento y salto del personaje.
- Detección de colisiones e interacción con objetos.
- Recolección de monedas.
- Obstáculos y peligros del entorno.
- Sistema de vidas del jugador.
- Sistema de cuestionarios históricos de verdadero y falso.
- Enemigos Conqueror con sistemas de vida y cuestionarios independientes.
- Mecánicas de patrullaje de enemigos.
- Sistema de desbloqueo de puertas al derrotar enemigos.
- Pantalla de victoria con opciones para reiniciar, regresar al menú principal o continuar.
- Efectos de sonido asociados a diferentes acciones del juego.
- Recursos gráficos en pixel art inspirados en la historia de Cartagena.
- Versión exportada para Windows.

## Contenido histórico

El nivel 1 se desarrolla en Cartagena e incorpora elementos de la historia y el patrimonio cultural colombiano, entre ellos:

- La India Catalina.
- El Castillo de San Felipe de Barajas.
- Preguntas históricas de verdadero y falso.
- Desafíos interactivos relacionados con la historia de Colombia.

## Requisitos

- Sistema operativo Windows compatible con la compilación.
- Todos los archivos de la compilación deben mantenerse juntos en una misma carpeta.
